## 機能一覧
* **気分・条件指定検索:** 「ご飯 / リラックス / アクティビティ」×「体力レベル」×「利用時間」を数タップで選択
* **直感3択提案:** 選択した条件に合ったおすすめスポットを3件カード表示（迷わせないUI）
* **スポット詳細 ＆ ナビ連携:** スポットの写真・説明の確認、Google Mapsへの直接遷移
* **マイページ（行ったところログ）:** 過去に決定したスポットを一覧管理（タップで詳細の再確認が可能）
